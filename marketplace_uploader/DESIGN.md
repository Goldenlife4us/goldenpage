# AI 자동소싱 대량등록 시스템 설계서

> 목표: 키워드 입력 → 팔릴 상품 자동 발굴 → SEO 최적화 → 3채널 자동 업로드
> 상용 도구(셀러라이프 ₩50k/월) 대비 자체 운영 오픈소스 대안

---

## 전체 아키텍처

```
┌─────────────────────────────────────────────────────────┐
│                   CLI / 실행 인터페이스                    │
│   python cli/source.py "텀블러"                          │
│   python cli/optimize.py                                │
│   python cli/upload.py --channel smartstore             │
└──────────────┬──────────────────────────────────────────┘
               │
   ┌───────────▼───────────┐
   │   1. SOURCING ENGINE  │  "팔릴 상품 찾기"
   │   ─────────────────   │
   │   도매꾹 OpenAPI       │  ← 소싱처 상품 목록
   │   네이버 검색광고 API   │  ← 키워드 검색량/경쟁강도
   │   demand_scorer.py    │  ← 황금키워드 판별
   └───────────┬───────────┘
               │ 후보 상품 목록
   ┌───────────▼───────────┐
   │   2. AI ENGINE        │  "SEO 최적화 + 상품기획"
   │   ─────────────────   │
   │   Claude API          │  ← 상품명 자동 생성
   │   seo_optimizer.py    │  ← 채널별 규칙 적용
   │   seo_validator.py    │  ← 위반 항목 체크
   └───────────┬───────────┘
               │ SEO 최적화된 마스터 DB
   ┌───────────▼───────────┐
   │   3. CHANNEL ENGINE   │  "채널별 파일 생성 + 업로드"
   │   ─────────────────   │
   │   (기존) xlsx 변환     │  ← 수동 업로드용
   │   smartstore_api.py   │  ← 네이버 커머스 API 자동업로드
   │   coupang_api.py      │  ← 쿠팡 WING API 자동업로드
   │   eleventh_api.py     │  ← 11번가 API 자동업로드
   └───────────────────────┘
```

## 핵심 판단 로직 - "황금키워드" 공식

```
황금지수 = 검색량 / sqrt(상품수)

판단 기준:
  황금지수 > 1.0   → 팔릴 가능성 높음 (소싱 추천)
  황금지수 0.5~1.0 → 보통 (추가 검토 필요)
  황금지수 < 0.5   → 경쟁 과다 (비추천)

추가 필터:
  - 원가 대비 마진율 30% 이상
  - 재고 회전 가능한 가격대 (5천~10만원)
  - 계절성 없는 상품 우선
```

## 채널별 SEO 최신 규칙 (2025~2026)

### 네이버 스마트스토어
```
알고리즘 3요소: 적합도 > 인기도 > 신뢰도

상품명 규칙:
  ✅ 허용: 브랜드 + 상품명 + 핵심속성 + 용량/사이즈
  ✅ 허용 특수문자: ( ) - · [ ] / & + , ~ .
  ❌ 금지: 셀러명, 쇼핑몰명, 할인/쿠폰 문구
  ❌ 금지: 같은 단어 3회 이상 반복
  ❌ 금지: 관련없는 브랜드명, 연예인명

태그 전략:
  - 연관 키워드 10~20개
  - 검색량 많은 키워드 우선
  - 카테고리 속성과 일치하는 태그
```

### 쿠팡
```
알고리즘 5요소: 검색관련도, 판매이력, 리뷰/평점, 전환율, 썸네일

상품명 규칙:
  ✅ 80자 이내
  ✅ 핵심 키워드는 앞 40자 안에 배치
  ✅ 3~5개 핵심 키워드 자연스럽게
  ❌ 2025년부터: 썸네일 흰 배경 필수, 로고/문구 금지
  ❌ 특수문자 남용 금지

태그: 10~15개 적당
```

### 11번가
```
상품명 규칙:
  ✅ 브랜드 + 상품명 + 주요 특성
  ✅ 검색 키워드 자연스럽게 포함
  ❌ 과도한 특수문자
  ❌ 허위/과장 표현
```

## 데이터 흐름

```
[입력]
사용자가 키워드 입력: "텀블러"
          ↓
[소싱 탐색]
네이버 검색광고 API → 월간 검색량: 150,000 / 상품수: 45,000
황금지수 = 150,000 / sqrt(45,000) = 707 → 높음 ✅
          ↓
[소싱처 조회]
도매꾹 API → "텀블러" 검색 → 상품 50개 목록 수집
원가 7,000원 ~ 15,000원 상품 필터
          ↓
[마진 계산]
원가 8,500원 + 목표마진 35% + 채널수수료 → 스마트스토어 23,000원 추천
          ↓
[AI SEO 최적화]
Claude API → "스테인리스 보온텀블러 500ml 직장인 차량용" 생성
채널별 규칙 검증 → 위반 없음 ✅
          ↓
[마스터 DB 저장]
master_products.xlsx 자동 추가
          ↓
[채널별 업로드]
channel_smartstore.xlsx / channel_coupang.xlsx / channel_11st.xlsx 생성
(Phase 3: API 자동 업로드)
```
